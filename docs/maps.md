# Display-only street maps (current state and consolidation decision)

## What runs today

- **`/`: Mapbox GL JS 3** renders a full-screen Glendale street map with `mapbox://styles/mapbox/streets-v12` (or `dark-v11`). It needs a browser-visible `NEXT_PUBLIC_MAPBOX_TOKEN=pk.…` in ignored `.env.local` or the deployment's build environment. The browser requests Mapbox styles/tiles on page load when configured, **before a visitor taps**. A URL-restricted public token still identifies the site to Mapbox; it is not a secret. Mapbox logo and built-in attribution must remain visible. The homepage has local private flame marks, **not** publisher incidents; their symbol can be misread as active fires, so the map and frontend owners should review neutral bookmarks before a public demo.
- **`/prepare`: no map.** PR #14 replaced the earlier click-to-load MapLibre + [OpenFreeMap](https://openfreemap.org/) `liberty` area map with a read-only wildfire guide; `area-map.tsx`, `map-client.tsx` and the checklist are gone from `src/`. The `maplibre-gl` dependency and the `predev`/`prebuild` worker copy (`scripts/copy-map-worker.mjs`, ignored `public/vendor/maplibre/`) are still installed but have **no page using them**; removing them is a code follow-up for the map owner. Mapbox is the only renderer a visitor sees today. Do not claim an offline map: no tile package is installed.

The homepage camera starts at a **general Glendale display view** and then centers on the device location if the visitor allows it (see the README's [location behavior](../README.md#location-behavior)), not a Glenoaks Canyon zone or an analytic location, a Glenoaks Canyon zone, or an analytic location. The basemap supplies no official evacuation boundaries, current fire fronts, verified routes or a safety verdict. The separate NWS, fire/air and dated Glendale GIS adapters are not mapped onto these basemaps; production queries are paused. No offline tile package is installed. The service worker caches the homepage shell and `public/offline.html` (a static condensed guide), not external tiles, so the offline fallback is **not** an offline map or alert feed.

## Token, rights and operation

A Mapbox account, current [usage/billing review](https://www.mapbox.com/pricing/), [Mapbox GL JS license and terms](https://www.mapbox.com/legal/tos/), attribution and [privacy review](https://www.mapbox.com/legal/privacy/) are required before public deployment. Restrict the public `pk.` token to app origins (and explicitly allow local test origins when needed); **never** paste an `sk.` secret into any `NEXT_PUBLIC_*` variable. The current homepage lacks a validated `pk.`-only build guard and robust provider-error/offline feedback, so the map owner should add them. Mapbox GL JS is the proprietary browser SDK, not MapLibre; its SDK and style requests can send usage/telemetry to Mapbox. A Mapbox token in an ignored local env file is safe from Git but is **not hidden from the browser**. Review allowed domains, traffic, billing and current offline rights. Do not pre-cache Mapbox web tiles without permission.

MapLibre 6's same-origin module worker and shared bundle are still copied from the installed package into ignored `public/vendor/maplibre/` by `predev`/`prebuild`, including its BSD-3 `LICENSE.txt`, although no page loads them since PR #14. If OpenFreeMap returns, OpenStreetMap is underlying map data, **not** permission to bulk-download its standard tile service. Review [OSM tile usage policy](https://operations.osmfoundation.org/policies/tiles/) and the OpenFreeMap provider's terms before scale or offline work. Neither provider supplies an evacuation boundary.

To add a sourced zone overlay later: confirm an actual issuing agency, geometry/zone IDs, jurisdiction, publication, vintage, rights, coverage and failure states; test point-in-polygon against the **publisher's** features on the server. A camera centre, saved private mark, City neighborhood or hazard class cannot substitute for that evidence. Keep official notices, standing hazards, planning models and unverified observations visibly separate. See [source roadmap](source-roadmap.md) and [source policy](source-policy.md).

The homepage map also has a directions drawer (location, an automatic shelter route and an on-request escape route, all on stubbed, unverified data), documented in the [README](../README.md#routes--shelters-location--routing).
