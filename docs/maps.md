# Display-only street map

The resident page includes a **click-to-load** interactive MapLibre map using [OpenFreeMap](https://openfreemap.org/) `liberty` style ([style URL](https://tiles.openfreemap.org/styles/liberty)). OpenFreeMap serves map tiles built from [OpenMapTiles](https://openmaptiles.org/) and [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Map attribution is visible alongside the map and in its provider's control. The camera starts at a **general Glendale view**, not a personal location or the Glenoaks Canyon centroid. Clicking to load sends tile requests to the external provider; the UI does not request geolocation or send the saved neighborhood to it.

MapLibre 6's same-origin module worker and shared bundle are copied from the installed package into ignored `public/vendor/maplibre/` by `predev`/`prebuild`; do not hand-edit or commit those generated dependency files. The copy also includes MapLibre's BSD-3 `LICENSE.txt` at `/vendor/maplibre/LICENSE.txt`. This avoids Next/Turbopack's worker URL resolution issue and keeps the installed package version authoritative. Use `npm run dev` or `npm run build` (or their `make` wrappers), **not** bare `next dev`/`next build`, so the copy hook runs. The map has **no official evacuation zones, incidents, routes, hazard polygons or live data**. It cannot answer “Am I in a zone?”, “Which way should I evacuate?”, or “Is it safe here?”. The NWS route and Glendale GIS MCP are separate from this basemap and are not mapped. The service worker does not intercept/cache external tiles. Internet is needed even if the offline checklist page works. An unavailable map must not hide official links or preparation content.

**OpenMap/OpenStreetMap terms:** OpenStreetMap is underlying map data, not a free production tile-hosting promise. OpenFreeMap is the external tile/style service; MapLibre GL JS is the browser renderer. These are three different roles. Do not swap in `tile.openstreetmap.org` for heavy traffic or offline tile downloads; review the [OSM tile usage policy](https://operations.osmfoundation.org/policies/tiles/) and chosen provider's current usage, attribution and privacy terms before deployment. A self-hosted or licensed PMTiles extract could support offline context later, but would require file-size, attribution, update and rights decisions. Neither option supplies an evacuation boundary.

To add a sourced zone overlay later: identify an actual issuing agency, confirm geometry/zone identifiers, jurisdiction, publication and legal reuse; record a dataset version, source/checked timestamp and explicit failure states; test point-in-polygon against the publisher's features on the server. A City neighborhood label or basemap road polygon must never substitute for that evidence. Keep styling and accessibility separate for official notices, standing hazards and community observations. Review [source roadmap](source-roadmap.md) first.

This page describes the display-only street map on `/prepare`. The homepage map (fire marks plus location and routes, built on stubbed, unverified data) uses Mapbox instead and is documented in the [README](../README.md#routes--shelters-location--routing).
